# Sole

An iOS pedometer app built with SwiftUI.

## Requirements

- Xcode 16 or later
- iOS 17.0+

## Getting started

Open `Sole.xcodeproj` in Xcode and run the `Sole` scheme on a simulator or device.

To build from the command line:

```sh
xcodebuild -project Sole.xcodeproj -scheme Sole -destination 'generic/platform=iOS Simulator' build
```
